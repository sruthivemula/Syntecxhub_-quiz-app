# 🎯 Interactive Quiz App

A modern and responsive Quiz Application built using **HTML, CSS, and JavaScript**. This project allows users to test their web development knowledge through multiple-choice questions and receive a final score at the end.

## 🚀 Features

* Home Page with Start Quiz button
* Multiple Choice Questions
* One Question Displayed at a Time
* Next Button Navigation
* Submit Button on Final Question
* Score Calculation
* Progress Bar
* Responsive User Interface
* Animated Gradient Background
* Restart Quiz Functionality

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🎮 How to Use

1. Open the application in your browser.
2. Click **Start Quiz**.
3. Select an answer for each question.
4. Click **Next** to move to the next question.
5. Click **Submit** on the last question.
6. View your final score.
7. Click **Restart Quiz** to try again.
